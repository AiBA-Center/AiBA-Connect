กำหนดการเคลื่อนกล้องและการเคลื่อนไหวทีละช็อต สำหรับ Google Flow

พบงานที่ทำค้างไว้ในหน้านี้

ใน Flow ให้เลือกโหมด "Frames to Video" แล้วอัปโหลดภาพนิ่งเป็นเฟรมแรกของแต่ละช็อต จากนั้นวาง Prompt ที่ได้จากที่นี่ทีละช็อต — หัวใจของการคุมการเคลื่อนไหวคือบอกให้ชัด 3 อย่าง: กล้องขยับยังไง · อะไรในภาพขยับ · อะไรห้ามเปลี่ยน

2ความยาวแต่ละช็อต

Flow สร้างคลิปได้ครั้งละประมาณ 8 วินาที

3สไตล์ภาพและแสงรวมของทั้ง 3 ช็อต

ใช้ค่าเดียวกันทุกช็อต เพื่อให้ตัดต่อกันแล้วดูเป็นวิดีโอเดียวกัน

4 สิ่งที่ห้ามเปลี่ยน เลือกได้หลายข้อ

ส่วนนี้สำคัญมาก ช่วยให้ AI ไม่เปลี่ยนหน้าตา สินค้า หรือองค์ประกอบของภาพต้นฉบับ

5ภาษาของ Prompt

Flow / Veo เข้าใจภาษาอังกฤษได้แม่นยำกว่า แนะนำให้ใช้อังกฤษ

Prompt สำหรับ Flow พร้อมแล้ว

วางทีละช็อต: อัปโหลดภาพนิ่งของช็อตนั้นเป็นเฟรมแรก แล้ววาง Prompt ของช็อตเดียวกัน (เปลี่ยนตัวเลือกด้านบนได้ตลอด ข้อความจะอัปเดตให้เอง)

ใน Google Flow: สร้างทีละช็อต (อัปโหลดภาพ → วาง Prompt → Generate) ทำครบ 3 ช็อตแล้วดาวน์โหลดมาสั่งตัดใน CapCut
